    Define the problem

    A physical therapist helps people recover movement after injury. She needs simple joint models to show how joints move. Your task is to design a joint model that shows hinge movement, like a knee or an elbow.

    Globally, about 1 in 5 adults over 60 suffer from osteoarthritis, which causes pain and reduced mobility. Joint models help people understand their movement and recover after injury.

    Team roles
    • Leader: keeps the team on task.
    • Material Manager: chooses and tracks the parts.
    • Reporter: explains the design to the class.
    • Testing Supervisor: runs the tests and records results.
    Parts: needed and not needed

    Needed: Kidsuno mainboard, USB cable, grey 270° servo, 20 cm or 30 cm wires, building blocks (beams, connectors, axle, gear, base plate).
    Not needed here: DC motor, wheels, ultrasonic sensor, buzzer, joystick, LED, IR receiver, remote, temperature sensor.

    Technology in focus: the servo motor
    • A servo turns to a specific angle and holds it. It does not spin freely like a fan.
    • You control how far it turns with code, from 0° to 180°.
    • With a servo you can move robot arms, move parts to exact positions, and create sweeping movements.
    • A DC motor only spins round and round, so it cannot stop at an exact joint angle.
    • Your kit has two servos. Use the grey 270° servo: it turns to exact angles (up to 270°, which is why the book says the joint moves 270°). The orange 360° servo spins round continuously, so it cannot hold a joint angle.
    Build steps from the book
    1. Step 1: stand two long yellow beams side by side and join them with a red connector (an H shape).
    2. Step 2: put the blue bent beam at the top and push an axle through the top holes. This is the hinge joint (knee).
    3. Step 3: attach the yellow frame to the side for support, and add green bricks at the bottom as the foot (ankle).
    4. Step 4: wire the servo to the Kidsuno mainboard: Brown → GND, Red → V, Orange → D13.
    5. Step 5: put a gear on the hinge axle, stand the servo on a yellow brick, and join servo and gear with a long black axle.
    6. Step 6: slide the servo up to the gear so the joint is firm.

    How the Sweep program works
    1. #include <Servo.h> loads the servo library. Servo myservo; creates the servo.
    2. myservo.attach(13); tells the board the servo is on pin 13. The book example says 9: change it to 13.
    3. The first for loop counts pos from 0 up to 180, one degree at a time.
    4. myservo.write(pos); moves the joint to that angle, and delay(15); waits 15 ms.
    5. The second for loop counts back from 180 to 0, so the joint closes again.
    6. Click Upload to send the program to the board.
    The finished code (copy and upload)
    1. Open the Arduino IDE and choose File → New.
    2. Delete everything in the window, then press Copy code below and paste it in.
    3. Choose Tools → Board → Arduino Uno and Tools → Port (the USB port of your board).
    4. Click Upload (the → arrow). The joint starts sweeping.

    Joint Sweep (one servo on D13)

    #include <Servo.h>

Servo myservo;  // create the servo
int pos = 0;    // the servo angle

void setup() {
  myservo.attach(13);  // orange signal wire is on D13
}

void loop() {
  for (pos = 0; pos <= 180; pos += 1) {  // open: 0 to 180 degrees
    myservo.write(pos);                  // move the joint to pos
    delay(15);                           // wait 15 ms
  }
  for (pos = 180; pos >= 0; pos -= 1) {  // close: 180 back to 0
    myservo.write(pos);
    delay(15);
  }
}

    Humanoid arm challenge (elbow servo on D13, wrist servo on D12). If your kit uses a different port for the second servo, change 12 to that number.

    #include <Servo.h>

Servo elbow;  // elbow servo on D13
Servo wrist;  // wrist servo on D12

void setup() {
  elbow.attach(13);
  wrist.attach(12);
  elbow.write(90);   // start straight
  wrist.write(90);
  delay(1000);
}

void loop() {
  for (int pos = 90; pos <= 150; pos += 1) {  // lift the forearm
    elbow.write(pos);
    delay(15);
  }
  for (int i = 0; i < 3; i++) {               // wave the hand 3 times
    for (int pos = 60; pos <= 120; pos += 1) { wrist.write(pos); delay(8); }
    for (int pos = 120; pos >= 60; pos -= 1) { wrist.write(pos); delay(8); }
  }
  wrist.write(90);
  for (int pos = 150; pos >= 90; pos -= 1) {  // lower the forearm
    elbow.write(pos);
    delay(15);
  }
  delay(1000);
}

    To make a real knee (it bends about 135°), change both 180s in the Sweep code to 135.

    Degrees and radians
    • A full circle is 360° = 2π radians, so 180° = π radians.
    • To change degrees to radians, multiply by π and divide by 180.
    • 90° = π/2, 270° = 3π/2 ≈ 4.71, and −270° = −3π/2.

    Troubleshooting
    • Servo does not move: check that the code says attach(13) and the orange wire is in D13.
    • Servo shakes or buzzes: the limb may be too heavy. Make it shorter or lighter.
    • Limb hits the frame: limit the angles in the code, for example 0 to 135 instead of 0 to 180.
    • Joint is loose on the axle: press the gear and the beam firmly onto the axle so they turn together.
    Why it matters

    Good Health means helping people move and live well. Joint models help people understand how joints bend, help engineers test designs that make movement safer, and can be shared to help more patients.

    8. Other ways to build a joint

    The book puts the servo right on the hinge. Your body does it differently: muscles and tendons pull on your bones. Study two designs that copy this, then invent your own.

    Example 1

    Tendon finger (rope and rubber band)

    Three finger pieces are joined by hinges. A rope runs under them like the tendon in your finger. When the servo pulls the rope, the whole finger curls. A rubber band on top pulls it straight again, like the muscle on the back of your hand.

    ✔ GoodOne servo moves three joints at once, just like a real finger.
    ✘ Watch outA rope can only pull. Without the rubber band, the finger will not straighten.

    Parts: servo motor, rope, rubber band, 3 short beams, 3 axles (hinge pins), base plate.

    Example 2

    Push-rod elbow (like the biceps muscle)

    The servo sits at the shoulder. A stiff rod joins the servo arm to the forearm, just below the elbow, where your biceps attaches. When the servo turns, the rod pulls the forearm up.

    ✔ GoodThe heavy servo is near the body, so the arm is lighter to move.
    ✘ Watch outThe rod must be the right length, or the arm will jam.

    Parts: servo motor, 2 long beams (upper arm and forearm), 1 beam as the rod, 3 axles, base plate.
